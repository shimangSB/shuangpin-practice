# 双拼练习

一个纯前端的双拼（Shuangpin）练习网站，无需联网、无需安装，打开即用。

## 快速开始

直接用浏览器打开 `index.html` 即可（无需服务器）。所有代码均为原生 HTML / CSS / JS，不依赖任何构建工具或网络资源。

另附打赏页面 `donate.html`（含微信 / 支付宝收款码），从页面右下角的「❤️ 打赏」可进入。

## 支持的方案

- 小鹤双拼（零声母用首字母，`er → er`）
- 微软双拼（零声母用 `o` 前缀，`ing` 在分号键）
- 自然码（`ing` 与 `uai` 同在 `y` 键）
- 搜狗双拼（键位与自然码基本一致）

四种方案均采用统一声母规则：`zh → v`、`ch → i`、`sh → u`。

## 练习模式

| 模式 | 说明 |
|------|------|
| 键位学习 | 查看当前方案的韵母键位表、声母特例、零声母规则 |
| 音节练习 | 看拼音音节，敲出两键编码 |
| 单字练习 | 看汉字敲编码（可开关拼音提示） |
| 词语练习 | 连续敲出词语每个字的编码 |
| 文章跟打 | 逐字跟打整句，统计速度与正确率 |
| 键位反查 | 反向记忆：韵母→键位（键盘输入）或 键位→韵母（选择） |
| 转换器 | 拼音 → 双拼实时转换 |

## 小鹤音形（可切换）

顶部「输入法」可切换 **双拼** / **小鹤音形**：

| 模式 | 说明 |
|------|------|
| 音形教学 | 笔画键、部件字根表、小字字根、拆分规则与示例 |
| 音形练习 | 看汉字敲完整音形码（音码 2 键 + 形码 2 键） |

音形码 = **音码**（小鹤双拼，2 键）+ **形码**（首形 + 末形，2 键），每字共 4 键。
笔画键：横 `a`、竖 `l`、撇 `p`、点 `d`、折 `v`、捺 `n`；字根按「声母 / 称谓」定键。

## 其它

- **舒适度设置**（顶栏 ⚙️ / 🌙 / 🔊）：
  - **敲击音效**：4 种音色（青轴 / 红轴 / 打字机 / 气泡）+ 音量调节，另有答对、答错提示音。
  - **深色模式**：顶栏 🌙 一键切换，夜间练习更护眼。
  - 答对彩带、猫爪光标等趣味开关。
  - 所有偏好自动保存到 `localStorage`。
- 统计（正确数 / 连击 / 累计）保存在浏览器 `localStorage` 中，点「清零统计」可重置。
- 顶部可随时切换方案，切换后当前练习会自动按新方案重新出题。
- **u/v 互通**（默认开启，右下角可关）：`u` 与 `v` 可互相代替，例如「局」既可打 `ju` 也可打 `jv`。
- 右上角「🧰 百宝箱」藏着一堆彩蛋：双拼冷知识、毒鸡汤、今日运势、火星文翻译。
- 所有词库（音节、单字、词语、文章、音形例字）均为常用内容，收录于 `data.js`。
