# 双拼练习

一个纯前端的双拼（Shuangpin）练习网站，无需联网、无需安装，打开即用。

## 快速开始

直接用浏览器打开 `index.html` 即可（无需服务器）。所有代码均为原生 HTML / CSS / JS，不依赖任何构建工具或网络资源。

另附打赏页面 `donate.html`（含微信 / 支付宝收款码），从页面右下角的「❤️ 打赏」可进入。

## 支持的方案

- 小鹤双拼（零声母用首字母，`er → er`）
- 微软双拼（零声母用 `o` 前缀，`ing` 在分号键）
- 自然码（`ing` 与 `uai` 同在 `y` 键）
- 搜狗双拼（键位与自然码基本一致）

四种方案均采用统一声母规则：`zh → v`、`ch → i`、`sh → u`。

## 练习模式

| 模式 | 说明 |
|------|------|
| 键位学习 | 查看当前方案的韵母键位表、声母特例、零声母规则 |
| 音节练习 | 看拼音音节，敲出两键编码 |
| 单字练习 | 看汉字敲编码（可开关拼音提示） |
| 词语练习 | 连续敲出词语每个字的编码 |
| 文章跟打 | 逐字跟打整句，统计速度与正确率 |
| 键位反查 | 反向记忆：韵母→键位（键盘输入）或 键位→韵母（选择） |
| 转换器 | 拼音 → 双拼实时转换 |

## 小鹤音形（可切换）

顶部「输入法」可切换 **双拼** / **小鹤音形**：

| 模式 | 说明 |
|------|------|
| 音形教学 | 笔画键、部件字根表、小字字根、拆分规则与示例 |
| 音形练习 | 看汉字敲完整音形码（音码 2 键 + 形码 2 键） |

音形码 = **音码**（小鹤双拼，2 键）+ **形码**（首形 + 末形，2 键），每字共 4 键。
笔画键：横 `a`、竖 `l`、撇 `p`、点 `d`、折 `v`、捺 `n`；字根按「声母 / 称谓」定键。

## 手机 / 平板

- 屏幕上的**键盘可以直接点按输入**（⌫ 为退格），所以手机上无需物理键盘，也不会被系统输入法「翻译」成汉字。
- 移动端布局已适配：导航横向滑动、键盘吸底铺满、弹窗从底部弹出、字号与点击区域按触屏优化，支持刘海屏安全区。
- 触屏设备会自动显示「点按键盘输入」提示。

## 其它

- **舒适度设置**（顶栏 ⚙️ / 🌙 / 🔊）：
  - **敲击音效**：4 种音色（青轴 / 红轴 / 打字机 / 气泡）+ 音量调节，另有答对、答错提示音。
  - **深色模式**：顶栏 🌙 一键切换，夜间练习更护眼。
  - 答对彩带、猫爪光标等趣味开关。
  - 所有偏好自动保存到 `localStorage`。
- 统计（正确数 / 连击 / 累计）保存在浏览器 `localStorage` 中，点「清零统计」可重置。
- 顶部可随时切换方案，切换后当前练习会自动按新方案重新出题。
- **u/v 互通**（默认开启，右下角可关）：`u` 与 `v` 可互相代替，例如「局」既可打 `ju` 也可打 `jv`。
- 右上角「🧰 百宝箱」藏着一堆彩蛋：双拼冷知识、毒鸡汤、今日运势、火星文翻译。
- 所有词库（音节、单字、词语、文章、音形例字）均为常用内容，收录于 `data.js`。

## 博客

仓库里的 `/blog/` 是一个静态博客，用最朴素的方式搭的：写 markdown，用一个 Python 脚本转成网页。

### 写一篇新文章

1. 在 `blog_src/` 里新建 `随便什么名字.md`
2. 开头加 front matter，下面正常写 markdown：

   ```markdown
   ---
   title: 文章标题
   date: 2026-01-15
   tags: [双拼, 输入法]
   summary: 一句话摘要，显示在列表页。
   ---
   ```

3. 双击 `tools/publish-blog.bat`（生成网页 + 提交 + 推送）

### 三个入口

| 文件 | 用途 |
| --- | --- |
| `tools/build-blog.bat` | 只生成网页，不发布 |
| `tools/preview-blog.bat` | 本地预览，浏览器打开 `http://localhost:8000/blog/` |
| `tools/publish-blog.bat` | 生成 + 提交 + 推送到 GitHub |

### 约定

- **`blog/` 里的东西全是自动生成的**，不要手动改；改了下次构建会被覆盖。
- 想改博客样式，改 `tools/build-blog.py` 里的 `CSS_CONTENT`。
- 文章不写 `title` 时会自动取正文第一个 `#` 标题；不写 `date` 会取文件修改时间。
- front matter 里写 `draft: true` 的文章只在本地存在，不会生成到 `blog/`。
- 博客只依赖 Python 标准库（PyYAML 是可选的），不装任何包也能跑。

### 支持的 markdown

标题、粗体、斜体、行内代码、代码块、链接、图片、有序/无序列表、引用、分隔线、表格、`<https://…>` 自动链接。

## 自测

转换逻辑附带了单元测试，可用 Node 运行：

```bash
node test.js
```

博客的 markdown 渲染自测：

```bash
python tools/test-md.py
```
